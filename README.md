# 🎓 Smart Campus Manager

A modern web-based event management platform designed to simplify campus event organization and participation. Smart Campus Manager enables students to discover and register for events while providing administrators with powerful tools to create, manage, and analyze event engagement in real time.

---

## 🚀 Overview

Smart Campus Manager is a full-stack web application built using Firebase services and modern frontend technologies. The platform streamlines event management by offering secure authentication, role-based access control, real-time database updates, and interactive analytics dashboards.

Students can browse upcoming events, register seamlessly, and track their participation history, while administrators can create events, manage registrations, and gain insights through real-time analytics.
